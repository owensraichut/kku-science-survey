## 🐔🐣 ระบบเยี่ยมชมบูธ “แม่ไก่ใส่ใจลูกเจี๊ยบ”

แบบสำรวจสำหรับผู้เข้าเยี่ยมชมบูธของ **โรงเรียนอุเทนพัฒนา สำนักงานเขตพื้นที่การศึกษามัธยมศึกษานครพนม (สพม.นครพนม)**
ซึ่งไปออกบูธนำเสนอหลักสูตร **“ศุกร์หรรษา พาน้องหนีเรียน”** — เรียนในห้อง 4 วัน แล้ววันศุกร์ออกไปลองทำอาชีพจริง
ในสถานประกอบการ โดยมีครูที่ปรึกษา (แม่ไก่) ดูแลผู้เรียนอย่างใกล้ชิด ในงาน **From Human Capital to Life Capital**

ผู้เข้าชมมาจากทั่วประเทศ ทั้งนักเรียนทุกระดับชั้น ครู ผู้บริหาร และบุคลากรทางการศึกษา
รวมแบบลงทะเบียน แบบสำรวจความสนใจในหลักสูตร และแบบประเมินความพึงพอใจไว้ในหน้าเดียว กรอกจบภายใน 3 นาที

### โครงสร้างแบบสำรวจ

**ตอนที่ 1 แบบลงทะเบียนผู้เข้าเยี่ยมชม**
ชื่อ-นามสกุล, เพศ, สถานะ (นักเรียน / ครู / ผู้บริหาร / ศึกษานิเทศก์ / ผู้ปกครอง / ผู้ประกอบการ / บุคคลทั่วไป),
ระดับชั้น, โรงเรียนเดิมหรือหน่วยงานที่สังกัด, จังหวัด (เลือกจาก 77 จังหวัด แยกตามภาค),
ช่วงเวลาที่เข้าชม, ช่องทางติดต่อ (ไม่บังคับ) และช่องทางที่ทราบข่าวการจัดบูธ

**ตอนที่ 2 ความสนใจในหลักสูตร**
- ประเด็นในหลักสูตรที่สนใจ 9 ตัวเลือก (เลือกได้หลายข้อ) เพื่อดูว่าจุดขายใดของหลักสูตรโดนใจผู้ชมที่สุด
- อาชีพหรือสายงานที่อยากออกไปลองทำจริง
- สำหรับครูและบุคลากรทางการศึกษา จะมีคำถามเพิ่มอัตโนมัติ 2 ข้อ คือ
  ความสนใจนำรูปแบบไปปรับใช้ และข้อกังวลหรืออุปสรรคที่คาดว่าจะพบ

**ตอนที่ 3 แบบประเมินความพึงพอใจ 15 ข้อ** (มาตรประมาณค่า 5 ระดับของลิเคิร์ท) แบ่งเป็น 4 ด้าน
1. ด้านเนื้อหาหลักสูตรและแนวคิดของกิจกรรม (4 ข้อ)
2. ด้านการนำเสนอและทีมงานประจำบูธ (4 ข้อ)
3. ด้านสื่อ นิทรรศการ และการจัดบูธ (4 ข้อ)
4. ด้านประโยชน์และการนำไปใช้ (3 ข้อ)

**ตอนที่ 4 ความพึงพอใจภาพรวมและข้อเสนอแนะ**
ให้ดาว 1 - 5 ดาว, สิ่งที่ประทับใจ และข้อเสนอแนะเพื่อการปรับปรุง

### ความสามารถของระบบ

- ✅ ตรวจสอบความครบถ้วนก่อนบันทึก ข้อที่ยังไม่ตอบจะถูกทำแถบสีแดงและเลื่อนหน้าจอไปให้อัตโนมัติ
- ✅ แถบแสดงความคืบหน้า (x / 15 ข้อ) แบบเรียลไทม์ และตัวบอกขั้นตอน 4 ขั้น
- ✅ คำถามสำหรับบุคลากรทางการศึกษาแสดงอัตโนมัติตามสถานะที่เลือก
- ✅ บัตรผู้เข้าเยี่ยมชมที่สั่งพิมพ์หรือบันทึกเป็นรูปได้ พร้อมสรุปคะแนนของผู้ตอบรายนั้น
- ✅ ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์ (เหมาะกับการวางแท็บเล็ตไว้หน้าบูธ)
- ✅ ถ้ายังไม่ตั้งค่า Supabase ระบบจะทำงานในโหมด LocalStorage ให้ทดลองใช้ได้ทันที

### แดชบอร์ดสรุปผล (`booth-dashboard.html`)

- อันดับประเด็นในหลักสูตรที่ผู้เข้าชมสนใจมากที่สุด และสัดส่วนผู้สนใจนำหลักสูตรไปปรับใช้
- ค่าเฉลี่ย (x̄) ส่วนเบี่ยงเบนมาตรฐาน (S.D.) และการแปลผล **รายข้อ รายด้าน และรวมทุกด้าน**
  ตามเกณฑ์ของ Best: 4.51-5.00 มากที่สุด | 3.51-4.50 มาก | 2.51-3.50 ปานกลาง | 1.51-2.50 น้อย | 1.00-1.50 น้อยที่สุด
- จัดอันดับข้อที่ได้คะแนนสูงสุด - ต่ำสุด เพื่อใช้เขียนสรุปผลในรายงาน
- กราฟ 8 ชุด: ประเด็นที่สนใจ, ค่าเฉลี่ยรายด้าน, ความสนใจนำไปปรับใช้, ภูมิภาคของผู้เข้าชม,
  สถานะผู้เข้าชม, การกระจายคะแนนภาพรวม, ช่องทางที่ทราบข่าว และช่วงเวลาที่เข้าชม
- รวบรวมคำตอบปลายเปิดทั้งหมด (อาชีพที่อยากลองทำ, ข้อกังวล, สิ่งที่ประทับใจ, ข้อเสนอแนะ)
  และทะเบียนผู้เข้าเยี่ยมชมพร้อมช่องค้นหา
- ดาวน์โหลดได้ 2 แบบ: **ข้อมูลดิบรายบุคคล (CSV)** และ **ตารางสรุป (CSV)** ที่รวมทั้งค่าเฉลี่ย/S.D./แปลผล
  และตารางความถี่ร้อยละของประเด็นที่สนใจ รองรับภาษาไทยใน Excel
- สั่งพิมพ์รายงานได้จากหน้าเว็บโดยตรง
- รหัสผ่านเริ่มต้นคือ `1234` แก้ไขได้ที่ตัวแปร `BOOTH_DASHBOARD_PASSCODE` ในไฟล์ `booth-dashboard.js`

### การตั้งค่าฐานข้อมูล

ระบบบูธใช้ **โปรเจกต์ Supabase คนละตัว** กับระบบแบบสำรวจเดิม จึงแยกไฟล์ตั้งค่าเป็น `booth-config.js`
(ระบบเดิมยังใช้ `config.js` เหมือนเดิม ไม่กระทบกัน)

สถานะปัจจุบัน: สร้างตาราง `booth_visits` ไว้แล้วในโปรเจกต์ **physics-utp** พร้อมใช้งานได้ทันที

หากต้องการย้ายไปโปรเจกต์อื่น
1. เปิด Supabase Dashboard ของโปรเจกต์ปลายทาง > SQL Editor แล้วรันสคริปต์ `booth_schema.sql`
2. แก้ `URL` และ `ANON_KEY` ในไฟล์ `booth-config.js` ให้ชี้ไปยังโปรเจกต์ใหม่

> หากปล่อยค่าใน `booth-config.js` ว่างไว้ ระบบจะทำงานในโหมด LocalStorage ให้ทดลองใช้ได้ทันที

### การนำขึ้นใช้งานจริง (Deploy)

เว็บนี้เป็น static ทั้งหมด ไม่ต้องใช้เซิร์ฟเวอร์ ใช้ GitHub Pages ได้ฟรี
1. รวมโค้ดเข้าแบรนช์ `main`
2. ไปที่ **Settings > Pages** เลือก Source เป็น *Deploy from a branch* > `main` > `/ (root)` แล้วกด Save
3. รอประมาณ 1 - 2 นาที จะได้ลิงก์
   - แบบประเมิน: `https://<username>.github.io/kku-science-survey/booth.html`
   - แดชบอร์ด: `https://<username>.github.io/kku-science-survey/booth-dashboard.html`
4. นำลิงก์แบบประเมินไปสร้าง QR Code ติดไว้หน้าบูธ

### การแก้ไขข้อคำถาม

ข้อคำถาม ตัวเลือก และข้อมูลของบูธทั้งหมดรวมอยู่ในไฟล์เดียวคือ **`booth-questions.js`**
แก้ไขที่ไฟล์นี้เพียงไฟล์เดียว ทั้งหน้าฟอร์มและหน้าแดชบอร์ดจะอัปเดตตามอัตโนมัติ

⚠️ หากเปิดเก็บข้อมูลจริงไปแล้ว ไม่ควรเปลี่ยนค่า `key` ของคำถามเดิม (เช่น `c1`, `p2`)
เพราะจะทำให้ข้อมูลที่บันทึกไว้ก่อนหน้าอ่านไม่ตรงข้อ

### ไฟล์ที่เกี่ยวข้อง

```
booth.html            หน้าแบบลงทะเบียน + แบบประเมินความพึงพอใจ
booth.js              ตรรกะการทำงานของหน้าฟอร์ม
booth-questions.js    นิยามข้อคำถาม/ตัวเลือก และฟังก์ชันคำนวณค่าเฉลี่ย S.D. และการแปลผล
booth-config.js       ค่าเชื่อมต่อ Supabase เฉพาะระบบบูธ (แยกจาก config.js ของระบบเดิม)
booth-dashboard.html  หน้าสรุปผลสำหรับคุณครูและทีมงานประจำบูธ
booth-dashboard.js    ตรรกะการสรุปผล กราฟ และการส่งออก CSV
booth.css             สไตล์เฉพาะของระบบบูธ (ใช้ต่อยอดจาก style.css)
booth_schema.sql      สคริปต์สร้างตารางและกำหนดสิทธิ์ใน Supabase
```
