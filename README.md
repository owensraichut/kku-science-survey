## 🐔🐣 ระบบเยี่ยมชมบูธ “แม่ไก่ใส่ใจลูกเจี๊ยบ”

แบบสำรวจสำหรับผู้เข้าเยี่ยมชมบูธของ **โรงเรียนอุเทนพัฒนา สำนักงานเขตพื้นที่การศึกษามัธยมศึกษานครพนม (สพม.นครพนม)**
รวมแบบลงทะเบียนและแบบประเมินความพึงพอใจไว้ในหน้าเดียว กรอกจบภายใน 2 - 3 นาที

### โครงสร้างแบบสำรวจ

**ตอนที่ 1 แบบลงทะเบียนผู้เข้าเยี่ยมชม**
ชื่อ-นามสกุล, เพศ, สถานะ (นักเรียน/ครู/ผู้ปกครอง/กรรมการ/บุคคลทั่วไป), ระดับการศึกษา,
โรงเรียนหรือหน่วยงาน, จังหวัด, ช่วงเวลาที่เข้าชม, ช่องทางติดต่อ (ไม่บังคับ)
และช่องทางที่ทราบข่าวการจัดบูธ (เลือกได้หลายข้อ)

**ตอนที่ 2 แบบประเมินความพึงพอใจ 15 ข้อ** (มาตรประมาณค่า 5 ระดับของลิเคิร์ท) แบ่งเป็น 4 ด้าน
1. ด้านเนื้อหาและองค์ความรู้ที่ได้รับ (4 ข้อ)
2. ด้านการนำเสนอและผู้ให้ข้อมูลประจำบูธ (4 ข้อ)
3. ด้านสื่อ นิทรรศการ และการจัดบูธ (4 ข้อ)
4. ด้านประโยชน์และการนำไปใช้ (3 ข้อ)

**ตอนที่ 3 ความพึงพอใจภาพรวมและข้อเสนอแนะ**
ให้ดาว 1 - 5 ดาว, สิ่งที่ประทับใจ และข้อเสนอแนะเพื่อการปรับปรุง

### ความสามารถของระบบ

- ✅ ตรวจสอบความครบถ้วนก่อนบันทึก ข้อที่ยังไม่ตอบจะถูกทำแถบสีแดงและเลื่อนหน้าจอไปให้อัตโนมัติ
- ✅ แถบแสดงความคืบหน้า (x / 15 ข้อ) แบบเรียลไทม์
- ✅ บัตรผู้เข้าเยี่ยมชมที่สั่งพิมพ์หรือบันทึกเป็นรูปได้ พร้อมสรุปคะแนนของผู้ตอบรายนั้น
- ✅ ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์ (เหมาะกับการวางแท็บเล็ตไว้หน้าบูธ)
- ✅ ถ้ายังไม่ตั้งค่า Supabase ระบบจะทำงานในโหมด LocalStorage ให้ทดลองใช้ได้ทันที

### แดชบอร์ดสรุปผล (`booth-dashboard.html`)

- ค่าเฉลี่ย (x̄) ส่วนเบี่ยงเบนมาตรฐาน (S.D.) และการแปลผล **รายข้อ รายด้าน และรวมทุกด้าน**
  ตามเกณฑ์ของ Best: 4.51-5.00 มากที่สุด | 3.51-4.50 มาก | 2.51-3.50 ปานกลาง | 1.51-2.50 น้อย | 1.00-1.50 น้อยที่สุด
- จัดอันดับข้อที่ได้คะแนนสูงสุด - ต่ำสุด เพื่อใช้เขียนสรุปผลในรายงาน
- กราฟค่าเฉลี่ยรายด้าน, สัดส่วนผู้เข้าชมตามสถานะ, การกระจายคะแนนภาพรวม, ช่องทางที่ทราบข่าว และช่วงเวลาที่เข้าชม
- รวบรวมข้อเสนอแนะปลายเปิดทั้งหมด และทะเบียนผู้เข้าเยี่ยมชมพร้อมช่องค้นหา
- ดาวน์โหลดได้ 2 แบบ: **ข้อมูลดิบรายบุคคล (CSV)** และ **ตารางสรุปค่าเฉลี่ย/S.D./แปลผล (CSV)** รองรับภาษาไทยใน Excel
- สั่งพิมพ์รายงานได้จากหน้าเว็บโดยตรง
- รหัสผ่านเริ่มต้นคือ `1234` แก้ไขได้ที่ตัวแปร `BOOTH_DASHBOARD_PASSCODE` ในไฟล์ `booth-dashboard.js`

### การติดตั้ง

1. **สร้างตารางในฐานข้อมูล** — เปิด Supabase Dashboard > SQL Editor แล้วรันสคริปต์ในไฟล์ `booth_schema.sql`
   (สคริปต์นี้สร้างตาราง `booth_visits` พร้อมเปิด Row Level Security ให้ผู้เข้าชมเพิ่มและอ่านข้อมูลได้ แต่แก้ไข/ลบไม่ได้)
2. **ตรวจสอบค่าเชื่อมต่อ** — ไฟล์ `config.js` ใช้ค่าเดียวกันกับระบบเดิม หากยังไม่ได้ตั้งค่า ระบบจะทำงานในโหมด LocalStorage
3. **เปิดใช้งาน** — เปิด `booth.html` ผ่านเว็บเซิร์ฟเวอร์หรือ GitHub Pages แล้วนำลิงก์ไปทำ QR Code ติดไว้หน้าบูธ

> หากยังไม่ได้รันสคริปต์ในข้อ 1 การกดบันทึกจะขึ้นข้อความแจ้งข้อผิดพลาดว่าไม่พบตาราง `booth_visits`

### การแก้ไขข้อคำถาม

ข้อคำถาม ตัวเลือก และข้อมูลของบูธทั้งหมดรวมอยู่ในไฟล์เดียวคือ **`booth-questions.js`**
แก้ไขที่ไฟล์นี้เพียงไฟล์เดียว ทั้งหน้าฟอร์มและหน้าแดชบอร์ดจะอัปเดตตามอัตโนมัติ

⚠️ หากเปิดเก็บข้อมูลจริงไปแล้ว ไม่ควรเปลี่ยนค่า `key` ของคำถามเดิม (เช่น `c1`, `p2`)
เพราะจะทำให้ข้อมูลที่บันทึกไว้ก่อนหน้าอ่านไม่ตรงข้อ

